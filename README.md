## ✨ Особенности (Features)
- 🤖Поддерживается не  ниже Android 7
- 🚀 Быстрая сборка и оптимизация веса APK.
- 🎨 Современный дизайн в стиле Material You.
- 🔒 Полная конфиденциальность (данные хранятся локально).
- 🌓 Поддержка темной и светлой темы (в будущем).

## 🛠️ Стек технологий (Tech Stack)
- **Язык:** Kotlin / Go
- **UI:** Jetpack Compose / XML Layouts
- **Архитектура:** MVVM / Clean Architecture
- **База данных:** Room / SQLite

## 🚀 Быстрый старт (Установка)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Sozdatel1/Tick-Task
   ```
2. Откройте проект в **Android Studio**.
3. Дождитесь окончания синхронизации Gradle.
4. Нажмите кнопку **Run** (зеленый треугольник) для запуска на эмуляторе или физическом устройстве.

## 📦 Как собрать APK вручную
1. В верхнем меню выберите `Build` -> `Generate App Bundels or APKs` -> `Generate APKs`.
2. После сборки нажмите на всплывающее уведомление **"locate"** в правом нижнем углу.
3. Готовый файл будет находиться по пути: `app/build/outputs/apk/debug/app-debug.apk`.
